6-1. 채팅 번역 안내 (2026년 10월 15일 추가)

채팅 번역 동의는 계정 전체에 적용되며 서버에 저장됩니다. 동의하지 않아도 일반 채팅을 이용할 수 있습니다. 나와 상대방이 각각 채팅 번역에 동의한 뒤의 새 텍스트 메시지만 번역 대상이며, 동의 전 대화는 대상이 아닙니다. 프로필·공개 글 번역의 동의와 대상 범위는 아래 제6-2항과 별개입니다.

동의만으로 원문을 전송하지는 않습니다. 수동 번역은 받은 메시지의 번역을 누를 때 요청하며, 자동 번역은 별도 설정으로 처음에는 꺼져 있습니다. 자동 번역을 켜면 화면에 표시된 대상 메시지를 이용 조건에 따라 번역하며, 과거 대화 전체를 일괄 전송하지 않습니다. 자동 번역 기본값·채팅방별 모드·원문 언어 선택은 이 기기의 계정별 설정으로 기억하며 계정 동의와는 다릅니다.

한국어·일본어 번역을 위해 대상 메시지의 원문과 언어 정보를 Google Cloud Translation(Basic v2·NMT)으로 보냅니다. 내가 상대방의 글을 번역하거나 상대방이 내 글을 번역할 때 모두 원문이 전송되며, 본문에 적힌 이름·연락처도 함께 전송됩니다. 사진·음성·통화 음성·스티커·답장 인용문·앞뒤 대화는 함께 보내지 않으며, 사용자 식별자나 채팅방 식별자를 번역 입력에 별도로 첨부하지 않습니다. 서울 서버에서 Google의 글로벌 API를 호출하므로 한국·일본 안에서만 처리된다고 보장하지 않습니다. 번역에는 오류나 뉘앙스 차이가 있을 수 있으며 원문을 계속 확인할 수 있습니다.

서버는 원문과 번역 결과를 메모리에서 일시 처리하며, 이음 서버의 번역 캐시 유효기간은 30초입니다. 번역 기능이 본문·번역 결과를 서버 데이터베이스에 새로 저장하거나 본문을 로그로 남기지는 않습니다. 기기의 암호화 저장과 재사용은 제6-3항을 따릅니다. 일반 채팅으로 저장된 원문에는 별도의 보유·삭제 방침이 적용됩니다. 동의 상태·시각·안내 버전과 이용 횟수·문자 수 등의 기록은 별도로 저장합니다.

「설정」 > 「꾸미기」 > 「채팅 번역」에서 「모든 대화의 번역 동의 철회」를 선택할 수 있습니다. 서버에 철회가 저장되면 이 계정의 모든 채팅에서 새 번역 요청을 중단합니다. 저장 오류가 발생하면 철회 완료가 아니므로 상태를 확인하고 다시 시도해 주세요. 내 화면에서 번역·자동 번역을 끄거나 로그아웃하는 것만으로 계정 동의가 철회되지는 않습니다. 화면에서 번역을 끄거나 동의를 철회해도 서버 캐시나 이미 Google에 전송한 내용이 동시에 즉시 삭제된다는 뜻은 아니며, 상대방이 이미 읽거나 복사한 내용은 회수할 수 없습니다.

6-2. 프로필·공개 글 번역 (2026년 10월 15일 추가)

공개 글 번역 동의(안내 버전 1)는 채팅 번역 동의와 별개로 계정 전체에 적용되며 서버에 저장됩니다. 읽는 사람과 작성자 모두 공개 글 번역에 동의해야 이용할 수 있습니다. 대상은 현재 공개 중인 자기소개, 지금 한마디, 일반·익명 게시글과 댓글, 투표 선택지입니다. 동의하기 전에 작성한 글도 현재 공개 중이면 번역 대상에 포함됩니다. 동의 이후의 새 메시지만 대상으로 하는 채팅 번역과 범위가 다릅니다. 숨김·삭제·차단 또는 지금 한마디의 만료 등으로 접근할 수 없는 내용은 번역하지 않습니다.

동의하거나 피드를 열고 스크롤하는 것만으로 번역을 자동 요청하지 않습니다. 이용자가 해당 텍스트의 「번역 보기」를 누를 때 번역을 요청하며, 「원문 보기」로 돌아갈 수 있습니다. 동의하지 않아도 원문을 볼 수 있고, 번역할 수 없는 경우에도 원문을 표시합니다.

번역 입력으로 선택한 텍스트와 언어 정보만 Google Cloud Translation(Basic v2)의 NMT 번역에 보냅니다. 닉네임·사진·계정 식별정보나 익명 작성자와 계정의 연결 정보는 별도로 첨부하지 않습니다. 다만 본문에 직접 적은 이름·연락처 등은 텍스트와 함께 전송됩니다. 앞뒤 게시글·댓글, 사진·음성은 함께 보내지 않습니다. Google의 글로벌 API를 사용하므로 한국·일본 안에서만 처리된다고 보장하지 않으며, 번역은 부정확할 수 있습니다.

서버는 원문과 번역 결과를 일시적으로 메모리에서 처리하고, 이음 서버의 번역 캐시 유효기간은 30초입니다. 이 번역 기능은 본문·번역 결과를 서버 데이터베이스에 새로 저장하지 않으며 본문을 로그로 남기지 않습니다. 기기의 암호화 저장과 재사용은 제6-3항을 따릅니다. 프로필·게시글·댓글로 저장된 원문은 기존 보유·삭제 방침에 따릅니다. 동의 상태·시각·안내 버전과 이용 횟수·문자 수 등 이용 제한에 필요한 기록은 서버에 별도로 저장합니다.

「설정」 > 「꾸미기」 > 「프로필·공개 글 번역」에서 「동의 철회」를 선택할 수 있습니다. 철회가 서버에 저장되면 이 계정의 새 공개 글 번역 요청과 다른 이용자가 내 공개 글을 새로 번역하는 요청이 중단됩니다. 채팅 번역 동의는 바뀌지 않으며 별도로 철회해야 합니다. 저장 오류가 발생하면 철회 완료가 아니므로 상태를 확인하고 다시 시도해 주세요.

원문 보기로 전환하거나 화면을 닫는 것만으로 계정 동의가 철회되지는 않습니다. 동의 철회나 화면 전환이 서버 캐시 또는 Google에 이미 전송한 내용의 즉시 삭제를 뜻하지 않으며, 다른 이용자가 이미 읽거나 복사한 번역도 회수할 수 없습니다.

6-3. 기기의 번역문 저장

기기 저장 기능을 지원하는 앱에서는 번역에 성공한 원문과 번역문을 본인 기기에 암호화해 계정별로 저장하고 최대 7일 동안 재사용할 수 있습니다. 이는 채팅 번역과 프로필·공개 글 번역 모두에 적용됩니다. 7일은 재사용 가능한 기간이며, 모든 저장 장치에서 정확히 그 시각에 삭제가 끝난다는 의미는 아닙니다.

재사용 전에도 서버에서 현재 원문과 접근 권한, 동의·차단·공개 상태를 확인합니다. 삭제·숨김·만료 또는 동의 철회 등으로 사용할 수 없는 내용은 저장된 번역으로 다시 표시하지 않습니다. 로그아웃하거나 계정을 변경하면 이전 로그인에서 저장한 번역은 재사용하지 않습니다. 기기에 저장된 번역문을 다른 계정이나 기기와 동기화하지 않습니다.

화면을 닫거나 원문 보기로 바꾸는 것만으로 기기의 암호화 저장본이나 서버 캐시가 모두 즉시 삭제되는 것은 아닙니다. 이음 서버의 30초 번역 캐시와 기기의 저장은 별개이며, 서버가 원문·번역 결과를 번역용 데이터베이스에 새로 저장하지 않는다는 제6-1항·제6-2항의 설명은 기기 저장을 제외한 서버 처리에 관한 설명입니다. 일반 대화·게시글의 원문, 나만의 메모 및 즐겨찾기에는 각각의 기존 보유·삭제 기준이 적용됩니다.

6-4. Apple Ads 가입 성과 측정 (iOS)

현재 출시 대상인 1.1.23(154)에서는 새 계정 연결형 Apple Ads 가입 성과 측정 기능을 활성화하지 않습니다. 이 버전에서는 이 기능의 신규 가입 동의를 요청하거나 새 가입 성과를 수집하지 않습니다. 기존 Google Analytics 이용 분석과 Android 광고 처리는 별도 안내에 따릅니다. 앱 전체의 AdServices 또는 광고 관련 데이터 처리가 중단된다는 뜻은 아닙니다.

아래의 처리·보관·철회 설명은 이 계정 연결형 기능을 별도로 활성화한 버전에 관한 안내이며, 현재 출시 대상 버전에서 신규 동의나 측정·집계 기능을 제공한다는 뜻은 아닙니다.

측정 기능이 활성화된 iOS 앱에서 신규 가입할 때 「[선택] 광고 성과 측정 동의」를 직접 선택한 경우에만 Apple AdServices를 이용합니다. 동의 항목은 처음에는 선택되어 있지 않으며, 동의하지 않거나 철회해도 가입·채팅 이용에 불이익이 없습니다. 앱을 설치하거나 서비스 이용약관에 동의했다는 이유만으로 이 측정에 동의한 것으로 보지 않습니다. 동의가 서버에 저장된 뒤, 신규 가입 완료 시 Apple Ads 광고의 가입 성과를 확인하고 중복 집계를 막기 위해 측정합니다. 기능 활성화 전 가입한 기존 회원의 광고 유입을 소급해 수집하거나 과거 가입 내역을 채우지 않습니다. 이 측정으로 광고 알림 수신 동의나 광고 개인화 설정을 변경하지 않습니다.

앱은 Apple이 발급한 단기 유효 토큰과 이음 내부 사용자 식별자를 이음 서버로 보냅니다. 서버는 토큰만 Apple의 광고 성과 확인 API로 보내 광고 연결 여부와 캠페인·광고 그룹, 국가·지역, 광고 위치, 다운로드·클릭·노출 관련 정보를 확인합니다. 이음 사용자 식별자, 닉네임, 연락처, 대화 내용은 이 요청에 첨부하지 않습니다. 이 측정 기능은 원본 토큰과 Apple의 응답 원문을 데이터베이스나 로그에 보관하지 않으며, 토큰을 기기에 저장하지 않습니다. 이 기능은 IDFA를 읽거나 추가 광고 SDK를 사용하지 않으며, ATT 권한 요청을 추가하지 않습니다. 이 선택 동의는 운영체제의 앱 추적 투명성(ATT) 권한과 별개이며 이를 대신하지 않습니다.

이음 서버에는 계정과 연결된 비공개 기록으로 동의·철회 상태, 안내 버전·결정 시각과 해당 계정을 확인하기 위한 가입 시각·내부 연결 정보를 보관합니다. 성과 처리 기록에는 가입 시각, 광고 연결 확인 상태, 중복 집계 방지용 임의의 처리 키와 시도 횟수·일시적 처리 상태 등을 보관합니다. 이 기록은 계정과 연결되어 있으므로 익명 정보가 아닙니다. 다른 이용자에게 공개하지 않습니다.

토큰 재사용을 막기 위해 토큰의 SHA-256 해시, 임의의 처리 키와 만료 시각을 별도로 보관합니다. 이 기록에는 사용자 식별자가 직접 들어 있지 않지만 계정별 비공개 기록과 연결될 수 있으므로 익명 정보로 취급하지 않습니다. 최초 기록 후 48시간을 만료 시각으로 설정하며, 이때부터 자동 삭제(TTL) 대상이 됩니다. 만료 시각과 실제 삭제 시각은 같지 않을 수 있습니다.

「설정」 > 「대화와 공개범위」 > 「광고 성과 측정」에서 「동의 철회」를 선택할 수 있습니다. 철회가 서버에 저장되면 새 측정을 허용하지 않고 새 성과 결과 저장을 중단하며, 계정별 성과 처리 기록을 삭제합니다. 다만 철회 전에 이미 시작된 처리에서는 토큰 조회나 전송이 철회 저장 후에도 완료될 수 있습니다. 철회 후 늦게 도착한 응답으로 삭제한 성과 기록을 다시 만들지 않습니다. 이미 Apple로 전송된 요청을 회수한다는 의미는 아닙니다. 철회 상태·안내 버전·결정 시각 등 최소 동의 기록은 측정 재개를 막기 위해 계정 삭제 때까지 남습니다. 로그아웃이나 앱 삭제만으로 동의가 철회되지는 않습니다. 저장 오류가 발생하면 철회 완료가 아니므로 상태를 확인하고 다시 시도해 주세요.

남아 있는 계정별 비공개 기록은 계정 삭제 처리 때 함께 삭제합니다. 철회나 계정 삭제로 계정과의 연결이 제거되어도 토큰 재사용 방지 기록은 만료 후 삭제 처리될 때까지 남을 수 있습니다. 사용자 식별자·토큰·해시를 포함하지 않는 일별·캠페인별 집계 건수는 계정 삭제 후에도 보관하며, 별도의 자동 만료 기간은 설정되어 있지 않습니다. 이미 완료된 집계는 철회나 탈퇴를 이유로 소급해 차감하지 않습니다.

집계는 동의한 신규 계정 중 확인된 가입 관측 건수이며 모든 설치·가입이나 서로 다른 사람의 수를 뜻하지 않습니다. 현재 측정 대상은 이음의 한국 Apple Ads 검색 결과 광고 중 지정한 캠페인·광고 그룹으로 한정됩니다. 광고 연결을 확인하지 못한 가입을 광고와 무관한 가입으로 단정하지 않습니다.

7. 개인정보 파기
